# Store

Учебный проект интернет-магазина на Python.

Реализованы классы Product и Category для хранения информации
о товарах и категориях.

Реализован автоматический подсчёт количества категорий и товаров.

## Домашнее задание 2

- Приватное хранение списка товаров категории.
- Добавление товаров через метод add_product().
- Вывод информации о товарах через геттер.
- Создание товаров через класс-метод new_product().
- Приватное хранение цены с использованием геттера и сеттера.
- Проверка корректности устанавливаемой цены.


## Домашнее задание 3

Реализованы магические методы:
- `Product.__str__()` — строковое представление товара.
- `Category.__str__()` — строковое представление категории.
- `Product.__add__()` — расчёт общей стоимости товаров.


## Домашнее задание 4

Добавлены классы-наследники Product:
- Smartphone — смартфоны.
- LawnGrass — газонная трава.

Реализовано ограничение сложения объектов разных классов.

Метод add_product() принимает только объекты Product и его наследников.
